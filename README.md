# Tally

## Description
Tally is a coursework tracker designed to help students organize assignments, manage deadlines, and plan their weekly workload.

## Features
- Dashboard to organize assignments by course, priority, due date, and workload
- Monthly calendar to view upcoming deadlines
- Node-based study path to prioritize assignments
- Manual and automatic assignment importing through APIs

## Target Audience
Students at all grade levels looking to better manage their coursework.

## Vision Statement
To empower students to take control of their academic success by simplifying coursework management, prioritizing deadlines, and turning overwhelming schedules into achievable goals.

## Development Methodology
Agile development using a Kanban board in Jira.
